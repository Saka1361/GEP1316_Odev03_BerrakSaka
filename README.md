# Animasyon Süresi Hesaplayıcısı

Bu proje, çizgi film ve animasyon çalışmalarında kare sayısı ile FPS (saniyedeki kare sayısı) değerlerini kullanarak animasyon süresini hesaplar.

## Kullanım

Program dosyası çalıştırıldıktan sonra dosya adı, toplam kare sayısı ve FPS değerleri girilir. Hesaplama, kare sayısının FPS değerine bölünmesiyle yapılır:

```text
Animasyon Süresi = Kare Sayısı / FPS
```

Python betiği şu komutla çalıştırılabilir:

```bash
python hesaplayici.py
```

## Dosyalar

- `hesaplayici.py`: Hatasız hesaplayıcı programı.
- `hesaplayici_hatali.py`: Mantık hatası içeren test sürümü.

## Testler

Program farklı kare sayıları, FPS değerleri, uç durumlar ve hatalı girişlerle test edilmiştir. Testlerin amacı beklenen sonuçları gözlenen sonuçlarla karşılaştırarak hata avı yapmak ve mantık hatalarını fark etmektir.
